# Link preview provenance

The local preview-card wrapper follows the shadcn Base UI composition and uses Base UI's `PreviewCard` primitive.

References reviewed 2026-09-16:

- https://ui.shadcn.com/r/styles/base-nova/hover-card.json
- https://base-ui.com/react/components/preview-card

The adjacent shadcn MIT notice is retained. Base UI provides intent delay, safe pointer travel, positioning, collision handling, and Escape dismissal. Preview content is supplementary: native links remain the accessible interface and retain ordinary, modified-click, keyboard, touch, and no-JavaScript navigation. Compact and non-hover devices do not load the enhancement.
